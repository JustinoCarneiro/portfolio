# Portfólio

Site de portfólio pessoal. O contrato canônico de trabalho está em `AGENTS.md`;
não o duplique aqui.

## Contexto rápido

- **Stack:** Vite + React (`react`, `react-dom`, `framer-motion`, `lucide-react`).
  Sem backend.
- **Estrutura:** `index.html`, `src/App.jsx`, `src/main.jsx`, `src/components/`,
  `src/index.css`, `public/assets_portfolio/`.
- **Validar:** `npm run lint` + `npm run build`. `npm run dev` para trabalhar.
